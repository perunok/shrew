# shrew documentation

- [KEYBINDINGS.md](KEYBINDINGS.md): every key, ex command and named command, the pickers and the About panel.
- [CONFIG.md](CONFIG.md): every `config.toml` setting, and the vimrc and Sublime Text import.
- [THEMES.md](THEMES.md): themes, accents, following the desktop, custom themes, importing color schemes, fonts.
- [GIT.md](GIT.md): git in shrew: how it works, what each view does, performance, troubleshooting.
- [CLI.md](CLI.md): the `srw` command, single instance, shrew as `$EDITOR`.
- [../CHANGELOG.md](../CHANGELOG.md): what changed in each release.

The pictures here are the real editor rendered headless: `screenshot.png` is the README hero, `screenshots/` holds
the README and THEMES.md galleries. `scripts/screenshots.sh` regenerates all of them.
